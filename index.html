Ash

Ash is a personal AI assistant that operates locally on hardware owned and operated by its developer (raju9112000@gmail.com). Ash connects to a small set of Google Workspace services only when explicitly asked, and only uses data from the single authorized account to fulfil that request.

What Ash does

  • Reads inbox messages and labels on explicit user request.
  • Sends mail or replies to threads only when the user asks it to.
  • Surfaces upcoming calendar events.
  • Reads and writes Google Drive, Docs, and Sheets files the user names.
  • Reads contacts the user has explicitly asked about.

What Ash does not do

  • Does not train any model on your data.
  • Does not share data with third parties.
  • Does not run any background telemetry or analytics.
  • Does not store tokens or data on a remote server; everything stays on the user's own hardware.

Operator
