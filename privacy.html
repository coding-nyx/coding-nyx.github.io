Privacy policy

This page describes how the personal AI assistant "Ash" handles data it accesses through Google APIs on behalf of its single authorized user. The full text below is the authoritative policy.

1. Who is the operator

Ash is operated by a single individual (raju9112000@gmail.com) on their own personal computing hardware. There is no organization, no company, no third-party vendor, and no remote backend. Ash runs locally on hardware controlled by the user.

2. What data Ash accesses

Ash can request the following Google account scopes, but only accesses the data within them when the user issues an explicit command:

  • Gmail read, send, and modify — mail content, mail metadata, label state. Used to search, triage, draft, and (on explicit user request) send or trash.
  • Google Calendar — event metadata (title, time, attendees). Used to surface upcoming agenda items.
  • Google Drive, Google Docs, Google Sheets — file metadata and content of files the user names. Used to read, edit, or create documents on explicit user request.
  • Google Contacts (read-only) — contact records. Used to enrich the mail composer with the right recipient name.

3. Where data lives

All access tokens, all temporary caches, and all logged outputs stay on the operator's local hardware. Nothing is uploaded to a remote service.

4. What Ash does not do with your data

  • Does not train any model (including the assistant itself) on your data.
  • Does not sell, rent, or share your data with any third party.
  • Does not run any analytics, telemetry, or background sync.
  • Does not use your data to build profiles or advertisements.

5. Data retention

The OAuth refresh token is stored on local hardware encrypted at rest by the host operating system. The user can revoke the token at any time at myaccount.google.com/permissions. After revocation, all cached data is purged on next agent startup.

6. Children

Ash is not directed at children and the operator does not knowingly collect data from anyone under 18.

7. Changes to this policy

Any change to data access or sharing behavior will be reflected on this page before it takes effect. The "last updated" date at the bottom of the page shows the current version.

8. Contact

For any question about this policy or to request a copy of all data Ash has accessed, contact raju9112000@gmail.com.
